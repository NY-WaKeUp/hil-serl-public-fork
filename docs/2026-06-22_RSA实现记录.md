# RSA（Random Scale Augmentation）实现记录

日期：2026-06-22

## 做了什么

为 wrist 广角/鱼眼相机接入 **RSA**，对抗尺度过拟合（CVPR 2026 [robo-fisheye](https://robo-fisheye.github.io/)）。

### 1. `data_augmentations.py`

新增：

- `random_scale(image, rng, scale_min, scale_max)` — 采样 $s \sim \mathcal{U}(0.7, 1.3)$，用 `jax.image.scale_and_translate` 在**固定 H×W** 内缩放（$s>1$ zoom-out 黑边，$s<1$ zoom-in 中心裁剪）
- `batched_random_scale(..., num_batch_dims=2)` — 与现有 `batched_random_crop` 同 batch 维约定

实现选用 `scale_and_translate` 而非 `resize`+pad，因后者在 `vmap`/`jit` 下输出尺寸为动态 traced 值会报错。

### 2. `launcher.py`

`make_batch_augmentation_func` 扩展参数：

| 参数 | 默认 | 含义 |
|------|------|------|
| `rsa_image_keys` | `None` | 启用 RSA 的相机 key 列表 |
| `rsa_scale_min` | `0.7` | 缩放下限 |
| `rsa_scale_max` | `1.3` | 缩放上限 |
| `crop_padding` | `4` | 所有相机仍做 random crop |

**Pipeline（按 key）**：

```
wrist: RSA → random_crop(4)
front: random_crop(4) only
```

`make_bc_agent` / `make_sac_pixel_agent*` 增加同名 kwargs 并传入 augmentation。

### 3. 训练配置

`examples/experiments/config.py`：

```python
rsa_image_keys: Optional[List[str]] = None
rsa_scale_min: float = 0.7
rsa_scale_max: float = 1.3
```

已启用 RSA 的实验：

- `aubo_pick_cube_sim` → `rsa_image_keys = [IMAGE_KEY_WRIST]`
- `aubo_pick_cube_real` → 同上

`panda_pick_cube_sim` 等默认 `rsa_image_keys=None`，行为与改前一致。

### 4. 训练入口

`train_rlpd.py` / `train_bc.py` / `train_hgdagger.py` 创建 agent 时传入 `config.rsa_image_keys` 等。

## 验证

```bash
source .venv/bin/activate
PYTHONPATH=serl_launcher python -c "
import jax, jax.numpy as jnp
from serl_launcher.vision.data_augmentations import batched_random_scale
img = jnp.ones((4,1,128,128,3))
out = batched_random_scale(img, jax.random.PRNGKey(0), num_batch_dims=2)
assert out.shape == img.shape
print('OK')
"
```

## 使用说明

Aubo 训练无需额外 flag；重新跑 learner 即对 **wrist** 启用 RSA。

若要对其他实验启用，在对应 `config.py` 加：

```python
rsa_image_keys = ["wrist"]  # 或 ["wrist_1", ...]
```

## 未改动的部分

- 推理 / eval **不做** RSA（仅训练 batch augmentation）
- `bc.py` 内 fallback `data_augmentation_fn` 仍为纯 crop（正常路径走 `augmentation_function`）
