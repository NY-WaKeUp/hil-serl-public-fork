# 2026-06-23 · 安全球替换安全盒

## 问题

安全盒（per-axis `np.clip`）是轴对齐包围盒，与 reset TCP 不对称的 `WORKSPACE_MARGIN` 导致不同方向的活动范围不一致——例如 `+X` 方向只给 5cm，`-X` 方向给 10cm。这不是一个工作的合理几何约束，且容易让不熟悉的人误配置。

## 修复

删掉盒式安全逻辑，改为**球式**。

### `aubo_i10_real_env.py` 改动

| 删除 | 新增 |
|------|------|
| `WORKSPACE_MARGIN_LOW/HIGH` | `SAFETY_SPHERE_RADIUS = 0.15` |
| `_xyz_low / _xyz_high` | `_safety_center` |
| `_update_safety_box_from_tcp()` | `_record_safety_center()` |
| `_apply_absolute_safety_box()` | — |
| 盒式 `_clip_safety_tcp()` | 球式 `_clip_safety_tcp()` |

核心逻辑：

```python
# 记录球心（reset 时调用）
self._safety_center = self._can_cmd_pos.copy()

# clamp：球面投影
delta = self._can_cmd_pos - self._safety_center
dist = np.linalg.norm(delta)
if dist > r:
    self._can_cmd_pos[:] = self._safety_center + delta * (r / dist)
```

叠加约束：
- 球面 clamp 后，再应用 `ABS_X_MIN` 硬地板（操作员方向）
- RPY 仍用 `ABS_POSE_LIMIT_LOW/HIGH[3:]` 的 per-axis clip

### `config.py` 改动

```python
# 旧：盒式
WORKSPACE_MARGIN_LOW  = [0.10, 0.12, 0.08, ...]
WORKSPACE_MARGIN_HIGH = [0.05, 0.12, 0.12, ...]
ABS_POSE_LIMIT_LOW    = [0.02, -1.35, 0.22, -pi, -0.6, -pi]
ABS_POSE_LIMIT_HIGH   = [0.22, -1.10, 0.42,  pi,  0.6,  pi]

# 新：球式
SAFETY_SPHERE_RADIUS = 0.15
ABS_X_MIN = 0.02
ABS_POSE_LIMIT_LOW   = [-inf, -inf, -inf, -pi, -0.6, -pi]  # XYZ 由球处理
ABS_POSE_LIMIT_HIGH  = [ inf,  inf,  inf,  pi,  0.6,  pi]  # 只约束 RPY
```

## 防御分层（简化后）

| 层 | 机制 | 默认 |
|---|---|---|
| 1 | `SAFETY_SPHERE_RADIUS` — 以 reset TCP 为球心，15cm 半径球 | 开 |
| 2 | `ABS_X_MIN` — 操作员方向硬地板 | 0.02（config.py） |
| 3 | `ABS_POSE_LIMIT[3:]` — RPY per-axis clip | pitch ±0.6 |

## 球 vs 盒——为什么球更好

|  | 盒 | 球 |
|---|---|---|
| 对称性 | 各向异性（asymmetric margin） | 各向同性（球对称） |
| 可解释性 | XYZ 六个边，难以直觉判断 | 一个半径值，直观 |
| 误配置风险 | 高（6 margin + 6 abs limit） | 低（1 个半径） |
| 代价 | O(1) per-axis clip | O(1) 向量范数 + 标量除法 |
