# RSA 重训：要不要换名字？

## 结论

| 项目 | 要不要改 | 建议 |
|------|----------|------|
| **`exp_name`** | **不必** | 继续 `aubo_pick_cube_sim`（config 里已有 `rsa_image_keys`） |
| **`CHECKPOINT_PATH`** | **必须** | 新目录，避免覆盖旧 ckpt / 误 resume |
| **demo pkl** | **不必** | RSA 只在训练 batch 里做，demo 可复用 |
| **wandb 曲线** | 建议区分 | 见下文 |

**不必新建实验文件夹**（不必再注册 `aubo_pick_cube_sim_rsa` 到 `mappings.py`），除非你想长期维护两套完全不同的 config。

---

## 推荐做法（最小改动）

训练前只改 checkpoint 路径：

```bash
export CHECKPOINT_PATH=~/hil-serl/checkpoints/aubo_pick_cube_sim_rsa
export DEMO_PATH=~/hil-serl/demo_data/aubo_pick_cube_sim_10_demos.pkl   # 原来的 demo 即可

cd ~/hil-serl/examples/experiments/aubo_pick_cube_sim
bash run_learner.sh
# 另一终端
bash run_actor.sh
```

评测：

```bash
export CHECKPOINT_PATH=~/hil-serl/checkpoints/aubo_pick_cube_sim_rsa
export EVAL_STEP=50000   # 按实际 step
bash run_eval.sh
```

### 命名示例

- `checkpoints/aubo_pick_cube_sim_rsa` — 简洁，推荐
- `checkpoints/aubo_pick_cube_sim_20260622_rsa` — 带日期，多轮实验不混
- 真机：`checkpoints/aubo_pick_cube_real_rsa`

---

## 为什么 `exp_name` 可以不变

- `exp_name` 只决定加载哪个 `TrainConfig`（环境、相机 key、RSA 开关等）。
- RSA 已写在 `aubo_pick_cube_sim/config.py` 的 `rsa_image_keys = ["wrist"]`。
- 旧 run 是**改代码之前**训的，权重与增强分布不同；新 run 用**新 checkpoint 目录**即可，不必 fork 整个实验包。

---

## 为什么 `CHECKPOINT_PATH` 必须变

`train_rlpd.py` 在 learner 启动时：

1. 若目录已存在且非 eval，会提示 **resume** 并加载旧 `checkpoint_*`。
2. 新 ckpt 会写入同目录，**覆盖**旧文件。
3. `buffer/`、`demo_buffer/` 也会挂在同一路径下。

用旧路径 = 可能从**无 RSA** 的权重接着训，或和旧 buffer 混在一起。

**不要**在已有旧训练的目录上「从头开新 run」除非你真的想 resume。

---

## wandb 怎么区分

当前 `make_wandb_logger(description=FLAGS.exp_name)`，两条 run 都会显示 `aubo_pick_cube_sim`。

可选：

1. **靠 checkpoint 路径记笔记**（零改代码）
2. 训练时加 seed / 自己在 wandb UI 改 run name
3. 若经常要区分，以后再给 `TrainConfig` 加 `wandb_run_suffix = "_rsa"`（当前未实现）

---

## 什么时候才需要新 `exp_name`

仅当你要**长期并行两套 config** 时，例如：

- 一套 `rsa_image_keys=None`（对照组）
- 一套 `rsa_image_keys=["wrist"]`（实验组）

那时再复制 `examples/experiments/aubo_pick_cube_sim_rsa/` 并注册 `mappings.py`。日常重训**不需要**。

---

## 对照表

| | 旧训练（无 RSA） | 新训练（有 RSA） |
|---|----------------|-----------------|
| exp_name | `aubo_pick_cube_sim` | 同左 |
| config | 当时代码无 RSA | 当前代码 |
| checkpoint | `checkpoints/aubo_pick_cube_sim` | **`..._rsa` 新目录** |
| demo | 已有 pkl | **复用**（`demo_data/aubo_pick_cube_sim_*_demos_*.pkl`，脚本自动选最新） |

---

## 常见报错：demo 路径不存在

`record_demos.py` 保存格式为带时间戳的文件名，例如：

```
demo_data/aubo_pick_cube_sim_20_demos_2026-06-22_09-04-56.pkl
```

**不是** `aubo_pick_cube_sim_10_demos.pkl`。

`run_learner.sh` 已改为：未设置 `DEMO_PATH` 时自动选用 `demo_data/` 下**最新的** `aubo_pick_cube_sim_*_demos_*.pkl`。

手动指定：

```bash
export DEMO_PATH=~/hil-serl/demo_data/aubo_pick_cube_sim_20_demos_2026-06-22_09-04-56.pkl
bash run_learner.sh
```
