# 2026-06-23 · Cube 朝上表面随机化

## 改动

每次 `reset` 除 XY 位置随机外，cube **姿态**也随机：

1. 从 **6 种稳定面朝上** 姿态中均匀采样（立方体每个面都可能朝上）
2. 再绕世界 **+Z 随机 yaw**（同色面朝上但水平朝向不同）
3. 按四元数计算 **贴桌高度**，避免穿模或悬空

## 关键文件

| 文件 | 内容 |
|------|------|
| `aubo_control_config.py` | `CUBE_FACE_UP_QUATS`（6×4，wxyz） |
| `aubo_i10_gym_env.py` | `_sample_block_quat`、`_cube_center_z_for_quat`、`random_block_orientation` |
| `aubo_pick_cube_sim/config.py` | `random_block_orientation=True` |

## 参数

```python
AuboPickCubeGymEnv(
    random_block_position=True,
    random_block_orientation=True,  # 关则恢复 identity 四元数
)
```

## 高度公式

立方体半边长 $s$，旋转矩阵 $R$，桌面 $z_{\text{table}}$：

$$z_{\text{center}} = z_{\text{table}} + s \sum_{j} |R_{2j}|$$

保证最低点落在桌面上。

## 注意

需 **重启 actor** 后生效。成功判定仍用 **reset 后** 的 `_z_init` 抬升量，与朝向无关。
