# 2026-06-22 · 真机键盘遥操优化（已实施）

## 能优化，且已改代码

此前卡顿主因是 **10Hz 才读一次键盘** + 每步观测太重，不是 32085 隧道坏了。

---

## 三项优化

### 1. 干预时 100Hz 读键盘（核心）

| 之前 | 之后 |
|------|------|
| 每 `env.step()`（10Hz）读一次键盘，10 个子步共用同一速度 | Space 介入时，**每个 CAN 子步（100Hz）** 读 `active_keys` |
| 双重 EMA | 子步用 `CAN_VEL_EMA_ALPHA=0.08`，与 smooth_teleop 一致 |

涉及文件：
- `aubo_velocity_control.py` — `update_from_active_keys()`
- `aubo_i10_real_env.py` — `_integrate_velocity_teleop()`
- `aubo_hil_wrappers.py` — 介入时设 `_teleop_keys_fn`

**策略步仍 10Hz**（与训练一致）；只有 **Space 介入** 走 100Hz 内环。

### 2. 观测不再堵控制

| 优化 | 作用 |
|------|------|
| `VideoCapture.read_latest()` | 取最新帧，不阻塞等下一帧 JPEG |
| `get_cached_proprio_state()` | 用 CAN 内部位姿，省每步 `get_current_waypoint()` SDK 往返 |
| `display_every_n=2`, `display_scale=2` | 降低 OpenCV 开销 |

### 3. 未改动的部分（刻意保留）

- `POLICY_HZ=10` — RL / eval 频率不变
- 非介入（策略控）仍 10Hz `update_from_action`
- 臂隧道 32085 不变

## 验证

```bash
source ~/hil-serl/.venv/bin/activate
export DISPLAY=:52.0
cd ~/hil-serl/examples
python -c "
import time, numpy as np
from experiments.mappings import get_train_config
env = get_train_config('aubo_pick_cube_real').get_environment(fake_env=False)
env.reset()
print('Space=介入后 WASD 试动')
z = np.zeros(7, np.float32)
t0 = time.time()
for _ in range(50):
    env.step(z)
print(f'50 steps in {time.time()-t0:.2f}s')
env.close()
"
```

对比优化前后：**按住 W 时臂应更连续**，不再明显「一格一格」。

## 优劣势

| 优势 | 风险 |
|------|------|
| 介入跟手大幅提升；训练 10Hz 不变 | 介入时 `tcp_vel` 来自滤波器，非 SDK 实测速度 |
| 少 1 次/步 SDK + 非阻塞取图 | 显示降频后画面略「跳」 |

**置信度**：机制正确性 — **高**；体感需你本地再试一次确认。
