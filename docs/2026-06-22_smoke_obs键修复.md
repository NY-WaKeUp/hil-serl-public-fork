# 2026-06-22 smoke KeyError: images 修复

## 现象

TCP / reset 均已成功，但：

```text
KeyError: 'images'
```

## 根因

`smoke_env.sh` 用了 `obs['images']`，与**训练时真实 obs 结构不一致**。

`get_environment()` 包装链：

```
AuboPickCubeRealEnv  →  pixels
AuboObsWrapper       →  {images, state}
SERLObsWrapper       →  {state, front, wrist}   # images 展平到顶层
ChunkingWrapper(1)   →  各键加 batch 维 (1, ...)
```

因此最终 `obs` **没有** `images` 键，而是：

```python
obs['front'].shape  # (1, 128, 128, 3)
obs['wrist'].shape  # (1, 128, 128, 3)
obs['state'].shape  # (1, N)
```

## 修复

`smoke_env.sh` 改为：

```python
shapes = {k: obs[k].shape for k in cfg.image_keys}
assert all(s[-3:] == (128, 128, 3) for s in shapes.values())
```

## 验证

```bash
./smoke_env.sh
# 期望: images {'front': (1, 128, 128, 3), 'wrist': (1, 128, 128, 3)}
#       SMOKE OK
```

**置信度**：高（与 `SERLObsWrapper.observation()` 实现一致）。
