# 2026-06-22 · `[`/`]` 夹爪无反应修复

## 现象

终端有 `Gripper close` / `Gripper open` 打印，但**物理夹爪不动**。

## 根因（置信度：高）

按键已收到。问题在**触发逻辑**：

1. **reset 默认 `gripper_closed=True`**（夹爪已是「关」）
2. 按 `[` 只改 controller 状态，**只有状态变化**才调 `_trigger_gripper`
3. 优化遥操时又在 `step` 里**提前** `unwrapped._gripper_closed = controller.gripper_closed`，边沿检测永远不满足 → **TCP 从不发送**

与 `smooth_teleop` 对比：后者在按键时**立即**发 gripper TCP，不依赖 env step 边沿。

## 修复

- 按 `[`/`]` **立即** `_trigger_gripper`（同 smooth_teleop）
- 去掉 step 前/子步内对 `_gripper_closed` 的提前同步

## 使用说明

| 键 | 作用 |
|----|------|
| `]` | **开**夹爪（建议先试这个） |
| `[` | **关**夹爪 |
| Space | 臂遥操需要；**夹爪键现在无需 Space 也会发 TCP** |

请重新跑遥操脚本验证。
